# App specification

## Problem

Describe the concrete problem in two or three sentences.

## Primary user

Describe who uses the app and in what setting.

## Primary journey

1. Entry state.
2. Essential action.
3. Useful result.

## Non-goals

- List capabilities that this version intentionally excludes.

## Acceptance criteria

- [ ] Define observable, testable outcomes.

## Data model and retention

Document each data type, where it is stored, schema version, migration approach, export/import format, and deletion behavior.

## Offline level

Choose Level 0 (online only), Level 1 (shell offline), or Level 2 (local-first), and define expected behavior during loss and restoration of connectivity.

## Error and empty states

Describe first use, empty results, permission denial, network failure, corrupt import, storage exhaustion, and unrecoverable errors that apply.

## Security and privacy

Document network destinations, third parties, permissions, sensitive data, and access control.
