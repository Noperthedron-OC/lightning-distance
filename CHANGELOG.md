# Changelog

## [1.0.0] — 2026-09-16

### Added
- Initial release: camera flash detection + microphone thunder detection
- Audio-only fallback mode when camera is denied
- Strike history within session
- Settings sliders: flash spike threshold, averaging window, thunder sensitivity, temperature
- Speed of sound calculation with temperature correction
- Timer overlay showing elapsed time since flash
- Intro modal with iOS/Android install instructions
- Dark stormy theme (black canvas, yellow accent, blue thunder, green result)
